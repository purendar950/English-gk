# English GK — SSC Practice

Topic-wise SSC English test application.

## Topics
Vocabulary, Synonyms, Antonyms, Idioms & Phrases, One Word Substitution, Spelling, Error Detection, Sentence Improvement, Fill in the Blanks, Cloze Test, Active & Passive Voice, Direct & Indirect Speech, and Miscellaneous.

Question files are stored independently under `data/`.

> The original large SSC HTML source is intentionally preserved until its question data can be safely extracted.
